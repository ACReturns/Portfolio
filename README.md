# Portfolio — Don Smith

**I make tools and things.** Automation engineer & AI developer · 20 years in games.

Live site: https://acreturns.github.io/Portfolio/

Hand-built static site: plain HTML, CSS and JavaScript, no framework and no build step. The fonts (Chakra Petch, Barlow, JetBrains Mono, all under the SIL Open Font License) are self-hosted, so the page makes no third-party requests except to the contact form endpoint.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The one-page site: Projects, Activity, Studio, Contact |
| `work/*.html` | Short write-ups for private / internal projects |
| `assets/css/site.css` | All styles (tokens at the top) |
| `assets/js/site.js` | Nav, Activity loader, studio camera feed, contact form |
| `assets/studio/` | Studio photos (WebP, 720×960) + the TV-static texture |
| `data/activity.json` | The Activity strip, regenerated by the deploy workflow |
| `scripts/build-activity.mjs` | Pulls recent commits from the showcase repos |
| `.github/workflows/deploy.yml` | Refreshes Activity every 6 hours and deploys to Pages |

## Before launch

1. **Pages source.** Under Settings → Pages → Build and deployment, set **Source: GitHub Actions**. The workflow deploys the site and refreshes the Activity strip on every push to `main` and every 6 hours.
2. **Studio links.** In `assets/js/site.js`, fill in `SITE_LINKS["adw-site"]` and `SITE_LINKS["adw-portfolio"]` with the Ancient Design Works URLs. Until then, those links scroll to the Studio section.
3. **Contact form.** Formspree endpoint `maygknpq` delivers to don_smith_2012@outlook.com. Send one test message after deploying.

## Common edits

- **Add a project:** copy a `<li>` in the Projects grid in `index.html`. The status class is `live` / `wip` / `private` on the card and `is-live` / `is-wip` / `is-private` on the label.
- **Show a repo in Activity:** add it to `REPOS` in `scripts/build-activity.mjs`.
- **Add studio photos:** export 720×960 WebP into `assets/studio/`, then add or extend a `.cam` block. The first image gets `src`, and the rest get `data-src`, which loads them on first hover.
