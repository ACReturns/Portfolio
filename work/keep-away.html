Keep Away

A two-player, local-multiplayer cage fighter in gritty pixel art — and an experiment in building a game by driving Unreal Engine with an AI agent.

Engine
Unreal Engine 5 · Paper2D
Tooling
Claude · Unreal MCP bridge
Status
Prototype · private repository

The game

Two fighters, one cage. A pistol spawns mid-match and the round is about keeping it away from your opponent. It’s built with Paper2D sprites, with keyboard, gamepad and touch controls planned so it can reach mobile too.

How it’s built

Instead of only writing a design document, I connected Claude to the live Unreal Editor through an MCP bridge and scripted Blueprints and level setup directly from conversation — the same augmented-coding workflow I use for tools.

Note

The project is in an early prototype stage and the repository is private.
