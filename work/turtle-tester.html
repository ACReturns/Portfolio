Turtle Tester

The build and deployment hub I built at Turtle Rock Studios — one app that took testers from “which build?” to “running on the console, bugs filed with logs.”

Where
Turtle Rock Studios
Role
Jr. Software Development Engineer
Stack
C# · Jenkins · PlayStation & Xbox SDKs · Jira API
Status
Used in production · internal

The problem

Getting a specific build onto a specific console was a chain of manual steps: dig through the build server for the right branch and version, download it, open a separate tool to push it to the PS4/PS5 or Xbox One/Series X devkit, then repeat when the build changed. On a bad day, just finding the right build could take hours.

What I built

Turtle Tester connected to the Jenkins build server and listed every build with its branch, file size and version number. One action downloaded a build and launched it, or deployed it straight to the target PlayStation or Xbox hardware.

Inside the game, testers could file a bug that went directly to Jira with the logs from the exact moment the issue happened attached, and send inputs into the running build for debugging.

The result

The build hunt, the platform tooling and the bug report collapsed into one place. Testers stopped hopping between applications, and bugs arrived in Jira with the evidence engineers needed to reproduce them.

Note

This is an internal studio tool, so there is no public code or screenshots. I’m happy to walk through how it worked in a conversation.
