Instant Price Estimator

A quote tool for the studio’s Custom Order page: drop in a 3D model, get a price range on the spot — no back-and-forth emails.

For
Ancient Design Works
Stack
JavaScript · STL / OBJ parsing
Status
In progress · part of the studio site

The problem

Every custom print request started with the same slow loop: a customer sends a file, I open it, estimate material and time, and email back a number. It doesn’t scale for a one-person shop.

What I built

A client-side intake page that parses uploaded STL and OBJ files right in the browser, computes the model’s volume, and turns that into an instant price range. The cost inputs are tunable, so the estimate tracks real material and machine costs. I prototyped it quickly with Claude.

Where it stands

It’s being built into the Ancient Design Works site. Once it’s live there, this page will link to it.
