ADW Orders App

Order management for the studio’s commissions, built so a one-person shop can quote, track and deliver without a team.

For
Ancient Design Works
Stack
Firebase · JavaScript
Status
In use · private repository

The problem

Commissions came in from word of mouth, small businesses and repeat customers — including a 100-unit production order — and tracking them in messages and notes didn’t hold up.

What I built

An order-management application with Firebase as the backend data store that follows each commission from intake to delivery.

Note

The repository is private because it holds customer data. A walkthrough is available on request.
